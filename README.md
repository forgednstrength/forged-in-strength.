# Forged in Strength, Rising Together

A responsive starter website for the community organization.

## Files
- `index.html` — website content and page structure
- `style.css` — colors, layout, mobile styling
- `script.js` — mobile navigation and automatic copyright year

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Open your GitHub repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder.
4. Click **Commit changes**.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then click **Save**.
8. Wait a few minutes and return to Settings → Pages for the live website address.

## Before publishing
- Replace the sample email in `index.html` with your real contact email.
- Replace the Facebook link with your organization's Facebook page URL.
- The sunflower emoji is a temporary visual symbol; you can replace it with your custom phoenix-and-sunflower logo when ready.
- This is a starter site. Donation processing, accounts, private community features, and a contact form that sends messages need separate services or backend setup.
